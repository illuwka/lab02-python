### Опис проєкту

- Тема проєкту: Набір Python утиліт
- Розроблені модулі:
  * `bmi_calculator.py` — калькулятор індексу маси тіла (ІМТ);
  * `calculatortemperature.py` — калькулятор перетворення температури з °C в K;
  * `calc.py` — файл створено в репозиторії, наразі порожній (заготовка під калькулятор).
- Функціональність кожного модуля:
  * **bmi_calculator.py** — запитує вагу (кг) і зріст (см), розраховує ІМТ за формулою `вага / зріст²` та визначає категорію за класифікацією ВООЗ (від дефіциту маси тіла до ожиріння III ступеня). Введені дані перевіряються: некоректне значення (літери, нуль, від'ємне число) викликає повторний запит, десяткова кома приймається нарівні з крапкою;
  * **calculatortemperature.py** — приймає температуру в градусах Цельсія та виводить її в кельвінах (`K = °C + 273.15`) з округленням до двох знаків. Нечислове введення обробляється через `try/except` з повідомленням про помилку;
  * **calc.py** — порожній файл, створений як заготовка для подальшої розробки.
